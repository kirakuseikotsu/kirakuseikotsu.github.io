きらく鍼灸整骨院 ホームページ（画像表示修正版）

【修正内容】
- トップページの施術室写真をCSS背景画像ではなくHTMLの画像要素で読み込む方式に変更
- 画像・QRコードの相対パスを ./images/... に統一
- 元の画像ファイルとページ構成は維持

【GitHubへのアップロード】
1. ZIPを解凍してください。
2. 解凍した中の index.html / access.html / price.html / style.css / script.js と images フォルダを、GitHubリポジトリの同じ階層（ルート）にアップロードしてください。
3. images フォルダごとアップロードし、中の画像ファイル名を変更しないでください。
4. GitHub Pagesの公開URLを開き、Ctrl + F5（Macは Cmd + Shift + R）で強制再読み込みしてください。

重要：ZIPファイルそのものをリポジトリに置くだけではホームページの画像は公開されません。必ず解凍して中身をアップロードしてください。
