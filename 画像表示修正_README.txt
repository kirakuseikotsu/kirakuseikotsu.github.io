きらく鍼灸整骨院 ホームページ画像表示修正版

このZIPは、現在のGitHubリポジトリのように画像ファイルをルート直下に置く構成に合わせ、
HTML/CSSの画像パスを修正したものです。

アップロード手順:
1. ZIPを解凍する
2. 解凍した中の access.html / index.html / price.html / style.css / script.js と画像ファイルを確認する
3. GitHubリポジトリの同名ファイルを置き換える
4. 画像ファイル (treatment-room.jpeg / line-qr.png / clinic-sign.jpeg / entrance.jpeg) もリポジトリ直下に置く
5. GitHub Pagesの公開ページを再読み込みする

注意: ZIPファイル自体ではなく、解凍した中身をアップロードしてください。
